# 原理解释

`"><a href=javascript:alert(1)>xss</a>`，这里闭合了前面的括号，然后生成了一条链接，这样我们点击这个链接就能执行xss，

最终网页会渲染出这样的：
`<input name=keyword value=""><a href=javascript:alert(1)>xss</a>">`
